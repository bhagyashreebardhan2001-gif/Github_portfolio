# Bhagyashree Bardhan — Geoinformatics Portfolio

Welcome to my personal geospatial portfolio.

I am an MSc Geoinformatics student with a background in Geography, interested in GIS, Remote Sensing, Geospatial Analysis, Web GIS, GeoAI, and urban spatial applications.

This portfolio showcases selected projects involving satellite imagery, land-use and land-cover mapping, vegetation analysis, geospatial data processing, interactive web mapping, and spatial visualization.

## Featured Projects

- **HYD LULC** — Interactive Land Use and Land Cover classification and visualization for Hyderabad using satellite imagery.
- **Magarpatta Satellite Explore** — Interactive exploration of satellite imagery and spatial data for Magarpatta, Pune.
- **Geospatial Big Data** — Processing, analysis, and visualization of large-scale geospatial datasets using Python-based tools.
- **Earthquakes World** — Interactive visualization of global earthquake data with spatial and map-based exploration.

GIS • Remote Sensing • Web GIS • JavaScript • HTML/CSS • Leaflet • Python • Pandas • GeoPandas • Jupyter • Google Earth Engine
